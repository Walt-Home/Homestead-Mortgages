Supermortgage

Gym

An environment is one job from our mortgage operations, set up so a model can be trained and measured on it: the task, the rules written out, the tools a model may use, and a grader that is our own engine. Every loan in it is synthetic. Pick one, draw a task, work it with the same tools a model gets, and submit an answer to see it graded field by field.

Held-out tasks are never shown here, because every reported score is measured on them. This page offers training tasks, at any seed and index, and the spec's own cases. Everything runs in this page, and nothing you type is sent anywhere.

Environments

A held-out score is how a model did on the 200 held-out tasks, which this page never shows. Training reads are how it did on training tasks, which you can open here; they are not scores.
